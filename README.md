# StudentGradeCalculator : ::

A simple student grade calculator for tracking student performance across assignments, tests, projects, and final exams.
asdasda
## Features
- Add and manage mulasasdsadtiple subjects or courses
- Enter scores for assignments, quizzes, tests, and final exams
- Calculate weighted totals automatically
- View overall percentage and letter grade
- Quick summary of academic performance

## Example
A course may use the following weighting:

- Assignments: 30%
- Quizzes: 20%
- Midterm: 20%
- Final Exam: 30%

The app calculates the final grade by applying the configured percentages to each score category.

## Getting Started
1. Open the project in your preferred IDE.
2. Restore dependencies if required.
3. Run the application.
4. Enter student scores and view the calculated results.

## Project Goals
This project is designed to make grade tracking easier for students, teachers, and academic planners by automating calculations and reducing manual errors.
